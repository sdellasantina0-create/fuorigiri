# Fuorigiri

Landing page in italiano dedicata ai motociclisti, realizzata con HTML, CSS e JavaScript senza dipendenze di compilazione.

Apri `dist/index.html` nel browser per visualizzarla.

- `dist/index.html`: struttura e contenuti.
- `dist/styles.css`: tutti gli stili e le regole responsive.
- `dist/script.js`: menu mobile e selettore di ispirazioni.
- `dist/theme.js`: tema chiaro/scuro, preferenza del dispositivo e salvataggio locale della scelta. Il pulsante nell’intestazione cambia tema; se il browser impedisce il salvataggio, il cambio resta disponibile per la pagina aperta.

Le immagini sono caricate da Unsplash e i font da Google Fonts: richiedono una connessione Internet. I contenuti sono dimostrativi.

La pubblicazione su Sites non è stata completata perché Node.js e Git non sono disponibili nel PATH dell'ambiente di esecuzione.
